# FinFuture — финансовый симулятор

Веб-приложение для учёта личных финансов в сомах: доходы, расходы, цели накопления и аналитика. Работает без сервера и сторонних библиотек, данные хранятся в браузере.

**Демо:** https://sadauhu.github.io/sada/

## Возможности

- Финансовая панель: общий баланс, доходы, расходы и накопления.
- Учёт операций: сумма, категория, описание, дата и тип (доход или расход), баланс пересчитывается автоматически.
- Цели накопления: сколько уже накоплено, сколько осталось и прогноз по ежемесячному взносу.
- Аналитика: график доходов и расходов, диаграмма расходов по категориям, процент потраченного бюджета.
- Сохранение данных в `localStorage`: всё остаётся после перезагрузки страницы.

### Дополнительные функции

- Выбор периода: 7 дней, месяц, год или всё время.
- Поиск по операциям и фильтр по датам.
- Предупреждение при приближении к лимиту расходов и при его превышении.
- Копирование отчёта в формате CSV (вставляется в Excel).
- Светлая и тёмная тема.
- Примерные данные при первом запуске (помечены «пример», удаляются крестиком).

## Как запустить

1. Скачайте репозиторий: `git clone https://github.com/sadauhu/sada.git`
2. Откройте файл `index.html` в браузере. Установка и сборка не нужны.

## Как это работает

- Баланс = доходы − расходы − накопления.
- Накопления вносятся через цели кнопкой «Внести». Удаление цели возвращает эти деньги на баланс.
- Лимит расходов считается по текущему календарному месяцу.
